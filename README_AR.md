# حساباتي — مشروع APK أندرويد (يعمل دون إنترنت)

هذا المشروع يحوّل نسخة إدارة المحل إلى تطبيق Android قابل للبناء عبر GitHub Actions، دون الحاجة إلى كمبيوتر محلي.

## الخصوصية والتخزين
- واجهة التطبيق مضمّنة بالكامل داخل APK في مجلد `www`.
- لا يوجد خادم خلفي ولا حساب مستخدم ولا مزامنة سحابية.
- بيانات المنتجات والمبيعات والمصاريف والجلسات تحفظ في `localStorage` الخاص بتطبيق Android WebView على الجهاز.
- أزلنا استيراد خط Google الخارجي حتى لا يحتاج التطبيق إلى طلبات شبكة لتشغيل الواجهة.
- تصدير النسخة الاحتياطية واستعادتها متاحان من داخل التطبيق. احتفظ بنسخة خارج الهاتف.
- حذف التطبيق أو مسح بياناته قد يحذف كل بياناته المحلية. لا تخزن بيانات مهمة قبل اختبار التصدير والاستعادة.

## إنشاء APK من الهاتف عبر GitHub
1. افتح `https://github.com` من متصفح الهاتف وأنشئ حسابًا إذا لم يكن لديك.
2. أنشئ مستودعًا جديدًا (New repository)، سمّه `hesabati-shop-android` واجعله Private، ثم أنشئه.
3. فك ضغط هذا الملف ZIP باستخدام تطبيق الملفات على الهاتف.
4. في المستودع اضغط **Add file → Upload files** وارفع كل محتويات المجلد، بما فيها `package.json` و`capacitor.config.json` ومجلد `www` ومجلد `.github/workflows`.
   - إذا لم يظهر مجلد `.github` عند اختيار الملفات، فعّل إظهار الملفات المخفية في مدير الملفات، أو استخدم محرر GitHub لإنشاء `.github/workflows/build-apk.yml` والصق محتوى الملف الموجود في المشروع.
5. اضغط **Commit changes**. سيبدأ البناء تلقائيًا.
6. افتح تبويب **Actions** في المستودع، واختر تشغيل **Build Hesabati APK** الذي اكتمل بنجاح.
7. انزل إلى قسم **Artifacts** وحمّل `hesabati-apk.zip`، ثم فك ضغطه على الهاتف.
8. افتح `app-debug.apk` وثبّته. قد يطلب Android السماح بتثبيت التطبيقات من هذا المصدر؛ لا تسمح إلا إذا كنت قد رفعت المشروع بنفسك وتثق به.

## إذا فشل البناء
افتح تبويب Actions، واختر التشغيل الأحمر، ثم أرسل لي نص الخطأ أو لقطة شاشة لأصلحه. لا يمكنني تشغيل البناء السحابي نيابةً عنك دون الوصول إلى حسابك ومستودعك.

## حدود النسخة
- هذه نسخة أولية، ليست نظام محاسبة قانونيًا معتمدًا.
- `localStorage` تخزين محلي ملائم لهذه النسخة، لكنه ليس تشفيرًا. استخدم قفل الهاتف وصدّر نسخة احتياطية بانتظام.
- ملف APK الناتج من هذا المسار هو Debug APK للتثبيت الشخصي، وليس إصدار متجر Google Play.
